Software & Tools

Open-source software developed by the lab and by Dr. Hou with collaborators. Most repositories are hosted under github.com/jiehou-lab and multicom-toolbox.

AutoRNA

AI agent · RNA

An AI agent built on open-source large language models that automates RNA motif structural analysis end to end. Developed by undergraduate researchers under the SLU FIRE and SURGE programs.

Poster (2025) →

RNASS

RNA secondary structure

Deep graph neural networks for RNA secondary-structure prediction (ICIBM 2024, oral presentation).

GitHub →

SAXSDom

Protein structure · SAXS

Assembles protein domain structures into full-length models using small-angle X-ray scattering (SAXS) data. Proteins, 2020.

GitHub → Paper →

DeepSF

Fold recognition

Deep convolutional neural network for mapping protein sequences directly to folds. Bioinformatics, 2018.

GitHub →

DNCON2

Contact prediction

Two-level deep convolutional neural networks for protein residue–residue contact prediction. Bioinformatics, 2018.

GitHub →

DeepDist

Distance prediction

Real-value inter-residue distance prediction with deep residual convolutional networks. BMC Bioinformatics, 2021.

GitHub →

DNSS2

Secondary structure

Improved ab initio protein secondary structure prediction using advanced deep learning architectures. Proteins, 2021.

GitHub →

DeepQA

Quality assessment

Single-model protein quality assessment with deep belief networks. BMC Bioinformatics, 2016.

GitHub →

ConEVA

Evaluation toolbox

A toolbox for comprehensive assessment of predicted protein contacts. BMC Bioinformatics, 2016.

GitHub →

GNET2

Omics · R package

Constructs gene regulatory networks from transcriptomic data via an E-M procedure that clusters genes into functional groups. Bioinformatics, 2020.

GitHub → Bioconductor →

MULTICOM

Structure prediction system

The MULTICOM protein structure prediction system (template-based and template-free modeling) developed in the Cheng lab, to which Dr. Hou contributed during CASP12–13.

GitHub →

CaTrace2Seq / Ca-Backbone-Prediction

Cryo-EM

Tools for assigning C-alpha traces to protein sequence and deep-learning backbone prediction from cryo-EM density maps (with Dr. Dong Si).

GitHub →
